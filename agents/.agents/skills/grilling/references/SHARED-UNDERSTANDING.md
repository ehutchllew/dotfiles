# Shared-understanding summary

Use this template to close a session when the user or a calling skill asks for a written record of the outcome:

```markdown
## Shared understanding

**Decisions**
1. <decision>: <chosen option> (because <reason>)
2. ...

**Assumptions** (things not discussed but taken as given)
- ...

**Out of scope**
- ...

**Open risks**
- ...

Reply "confirmed" to proceed, or correct any line.
```

The Assumptions section matters most: listing them is how you prove nothing was silently assumed. Leave a section out if it's empty.
